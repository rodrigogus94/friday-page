Política de Privacidade

Sexta-feira — última atualização: 11/11/2026. Voltar ao início

A Sexta-feira é um assistente pessoal que roda no computador do próprio usuário. Esta política explica quais dados da conta Google ela acessa quando o usuário a conecta, o que faz com eles e como o acesso pode ser removido.

1. Quais dados do Google são acessados

Apenas as permissões que o usuário autoriza na tela de consentimento do Google, e somente para atender a um pedido dele:

PermissãoPara que serve
Google Agenda (eventos)Criar, listar e cancelar compromissos.
Google Drive — arquivos criados pelo appCriar e acrescentar texto a documentos e planilhas que a própria Sexta-feira criou.
Google Drive — somente leituraBuscar e ler arquivos que o usuário pede para ler. Nada é editado, movido, compartilhado ou apagado.
Google TarefasCriar, consultar, concluir e apagar tarefas.
Gmail — leituraLer e resumir mensagens que o usuário pede para ler.
Gmail — envioEnviar uma mensagem escrita pelo usuário. Cada envio exige uma verificação adicional do usuário.
Contatos — somente leituraConsultar nomes e endereços de contatos quando o usuário pede.

2. Como os dados são usados

Os dados do Google são usados somente para executar o pedido que o usuário acabou de fazer à assistente, como "o que tenho na agenda amanhã?" ou "resume este e-mail". Não são usados para publicidade, perfilamento, venda ou qualquer outra finalidade.

3. Para onde os dados vão

  • Neste computador: o token de acesso é guardado em arquivo no próprio computador, protegido pelo Windows (DPAPI), e só abre na conta e no PC do usuário. O histórico das conversas, que pode incluir o resumo do que a assistente leu, também fica em um banco de dados local, que o usuário pode manter cifrado.
  • Provedor de inteligência artificial: para entender e responder ao pedido, o texto necessário (por exemplo, o conteúdo de um e-mail que o usuário pediu para resumir) é enviado ao provedor de IA que o usuário configurou — Anthropic (Claude) ou DeepSeek. Antes do envio, o conteúdo de origem externa passa por um filtro local que mascara dados sensíveis comuns (chaves de API, senhas, CPF, números de cartão). Esse filtro reduz o risco, mas não promete eliminá-lo.
  • Terceiros: os dados do Google não são vendidos, compartilhados nem transferidos a ninguém além do que está descrito acima, exceto se exigido por lei.

4. Uso limitado

O uso e a transferência de informações recebidas das APIs do Google por este aplicativo seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. Não há leitura dos dados por pessoas, a não ser que o próprio usuário as veja na tela do seu computador.

5. Quanto tempo ficam guardados

O token fica guardado até o usuário remover o acesso (item 6). O histórico local fica no computador do usuário até ele apagá-lo. O desenvolvedor não mantém servidor nem banco de dados próprios: não recebe nem armazena os dados do Google de ninguém.

6. Como remover o acesso

  • Revogue a permissão em myaccount.google.com/permissions, escolhendo "Sexta-feira" e "Remover acesso". Isso invalida o token imediatamente.
  • Apague o arquivo dados/google_token.bin da pasta do programa para remover o token do computador.
